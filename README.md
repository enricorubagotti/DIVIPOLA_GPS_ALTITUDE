vereda# DIVIPOLA_GPS_ALTITUDE
The file DIVIPOLA_GPS_ALTITUDE.csv contains GPS and altitude of all 7791 sub-counties ("Vereda") of Colombia.
The method is described below:

1) Download the file containing the GPS of all "veredas" from https://geoportal.dane.gov.co/servicios/descarga-y-metadatos/datos-geoestadisticos/?cod=112
2) Download 
GPS coordinates/altitudes of Colombia Counties
